Defusing a Logic Bomb

Win and lose

  • Disarm every module before the timer hits 0:00.
  • A wrong action is a strike. The bomb explodes on its last strike (3 by default). After a strike the timer runs faster.
  • A module is disarmed when its status light (top-right) turns green. Do modules in any order.
  • The timer module has no rules. A needy module (if present) never disarms: just keep answering it.

The one law

When a box lists numbered rules, check them top to bottom and use only the first rule that is TRUE.

Two reminders

  • P → Q is FALSE only when P is TRUE and Q is FALSE.
  • ∀ about nothing is TRUE. ∃ about nothing is FALSE.

LOGIC BOMB · MANUAL v2.0MODULES 1–2

1Wires

3 to 6 horizontal wires. Cut exactly one.
Wires are numbered from the top (wire 1 = top). “Last” means the lowest one.  R(w) red · B(w) blue · Y(w) yellow · K(w) black · W(w) white. The domain is the wires on the module.

3 wires

  1. ¬∃w R(w)cut wire 2
  2. ∀w (R(w) ∨ B(w))cut the last wire
  3. ∃w W(w)cut the last white wire
  4. otherwisecut wire 1

4 wires

  1. ∃!w R(w)cut the red wire
  2. ∀w ¬Y(w)cut wire 1
  3. ∃w K(w) ∧ b ≥ 2cut the last black wire
  4. otherwisecut wire 4

5 wires

  1. ∃w K(w) ∧ ∃w W(w)cut wire 4
  2. ∀w ¬R(w)cut wire 1
  3. ∃d ∈ D (d is odd)cut the last wire
  4. otherwisecut wire 2

6 wires

  1. ∀w ¬Y(w)cut wire 3
  2. ∃!w W(w)cut the white wire
  3. ∃w ∃v (w ≠ v ∧ R(w) ∧ R(v))cut the last red wire
  4. otherwisecut wire 6

2The Button

One big round button with a colored cap and a word on it. A light strip sits to its right.

Propositions

pThe button is red.
qThe label says TRUE.
rb ≥ 2 (two or more batteries)
sAt least one indicator is lit.

Rules

  1. p ∧ qTAP
  2. ¬p ∧ ¬rHOLD
  3. q ∨ sTAP
  4. otherwiseHOLD

TAP = press and let go right away.

Releasing a held button

While held, the strip lights up. Work out the strip’s set. Release when the timer shows a digit from that set in any position.

StripRelease on the digit in…
Blue{1, 2, 3, 4} ∩ {4, 5, 6}
White{1, 3, 5} − {3, 5}
Yellow{5, 6, 7} ∩ {1, 3, 5}
Red{x ∈ ℤ | 1 < x < 3}

Tip: work out all four sets before the Defuser presses. Once they are holding, they can only tell you the strip color.

3Set Keypad

Four square keys, each printed with a set.
Press the keys in order of cardinality, from the smallest set to the largest. No two keys have the same size. A correct key lights green; a wrong key is a strike (correct keys stay lit).

The sets

A = {1, 2, 3, 4}
B = {3, 4, 5}
C = {2, 4, 6, 8}
Universe 𝕌 = {1, 2, 3, 4, 5, 6, 7, 8}, so A′ = 𝕌 − A.

Careful: |∅| = 0 but |{∅}| = 1 (one element: the empty set). {A, B} has 2 elements: the sets A and B.

4Simon Maps

A diamond of four colored pads. It flashes a sequence that grows by one each stage.
For every flashed color x, the Defuser presses f(x), in the same order, for the whole sequence shown so far. Which function?  If V ≠ ∅ (serial has a vowel) use f. Otherwise use g.
If V ≠ ∅f = { (Red, Blue), (Blue, Red), (Green, Yellow), (Yellow, Green) }
If V = ∅g = { (Red, Yellow), (Blue, Green), (Green, Blue), (Yellow, Red) }

Read (Red, Blue) ∈ f as “f(Red) = Blue”: flashed red → press blue. The sequence has 3 to 5 stages. A wrong press is a strike and the stage starts over.

A screen showing a quantified statement and six word buttons. Three stages.
Domain: everyone in the class. T(x, y) means “x is taller than y”. Translate the screen into English, find that sentence below, and the Defuser presses the button with its code word.

6Venn Wires

4 to 6 vertical wires. Lights above, panels below.
Wires are numbered left to right. Each wire is red, blue, striped red-and-blue, or white. Each has an LED above it (on/off) and a panel below it (★ or blank).

Sets

Rwires with red on them (red or striped)
Bwires with blue on them (blue or striped)
Lwires whose LED is on
Swires with a ★ below
Cut every wire in K = (R ∩ L) ∪ (S − B).

Order doesn’t matter. Cutting a wire not in K is a strike. A white wire is in neither R nor B.

7Quantifier Grid

A green screen with a 3 × 3 grid of digits, and four round colored buttons.
Rows r go top to bottom, columns c go left to right, and x is the digit in row r, column c. Press the color of the first TRUE rule.
  1. ∃r ∀c (x is even) RED
  2. ∀r ∃c (x = 0) BLUE
  3. ∃c ∀r (x > 5) GREEN
  4. otherwise YELLOW
How to say them:
1. “Is there a row where every digit is even?”
2. “Does every row contain a 0?”
3. “Is there a column where every digit is bigger than 5?”
0 counts as even.

A screen with a formula in P and Q, four numbered T/F windows with arrows, and a SUBMIT key.
Set each window to the formula’s truth value in that row of the truth table, then press SUBMIT. Either arrow flips T ↔ F. A wrong SUBMIT is a strike.

NNeedy: Argument Check

A screen asks “VALID ARGUMENT?” with Y and N keys and a 2-digit countdown. It wakes up every so often.
When it shows an argument (premises, a line, then ∴ conclusion), press Y if it is valid and N if it is invalid, before the 40-second countdown ends. Wrong answer or time out = strike. Match the pattern:
VALID → press Y
p → q, p ∴ qmodus ponens
p → q, ¬q ∴ ¬pmodus tollens
p → q, q → r ∴ p → rhypothetical syllogism
p ∨ q, ¬p ∴ qdisjunctive syllogism
p ∴ p ∨ qaddition
p ∧ q ∴ psimplification
∀x P(x) ∴ P(c)universal instantiation
P(c) ∴ ∃x P(x)existential generalization
∀x (P(x) → Q(x)), P(c) ∴ Q(c)universal modus ponens
¬∀x P(x) ∴ ∃x ¬P(x)negating ∀
INVALID → press N
p → q, q ∴ paffirming the conclusion
p → q, ¬p ∴ ¬qdenying the hypothesis
p ∨ q, p ∴ ¬q“or” is not “exclusive or”
∀x (P(x) → Q(x)), Q(c) ∴ P(c)affirming the conclusion (∀)
∃x P(x) ∴ ∀x P(x)hasty generalization
¬∀x P(x) ∴ ∀x ¬P(x)bad negation

Why these are the hard parts

  • Vacuous truth. Wires rule ∀w ¬Y(w) is TRUE when there is no yellow wire at all.
  • Quantifier order. ∀x ∃y (everyone has a partner) is weaker than ∃y ∀x (one person works for everyone).
  • Sets of sets. {∅} is not empty. It has one element.
