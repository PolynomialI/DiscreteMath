Wires

  1. Count the wires (3–6).
  2. Wire 1 is the top wire. “Last” = lowest.
  3. Cut one wire.

R(w) red · B(w) blue · Y(w) yellow · K(w) black · W(w) white

3 wires

1¬∃w R(w)cut wire 2
2∀w (R(w) ∨ B(w))cut last wire
3∃w W(w)cut last white
4otherwisecut wire 1

4 wires

1∀w ¬Y(w)cut wire 1
2∃w K(w)cut last black
3∀w (R(w) ∨ Y(w))cut wire 3
4otherwisecut wire 4

5 wires

1∃w K(w) ∧ ∃w W(w)cut wire 4
2∀w ¬R(w)cut wire 1
3∃d ∈ D (d is odd)cut last wire
4otherwisecut wire 2

6 wires

1∀w ¬Y(w)cut wire 3
2∃w W(w)cut last white
3∃w ∃v (w ≠ v ∧ R(w) ∧ R(v))cut last red
4otherwisecut wire 6

The Button

  1. Find the first TRUE rule.
  2. TAP = press and let go.
  3. HOLD = keep holding; a strip lights up. Release using the table below.
pbutton is red
qlabel says TRUE
r2 or more batteries
san indicator is lit

Rules

2¬p ∧ ¬rHOLD

Stripthe digit in
Blue{1,2,3,4} ∩ {4,5,6}
White{1,3,5} − {3,5}
Yellow{5,6,7} ∩ {1,3,5}

The digit can be anywhere on the timer.

Simon Maps

  1. Colors flash in a sequence that grows each stage.

Quantifier Grid

  1. Rows r: top to bottom. Columns c: left to right.
  2. x = the digit at row r, column c.
  3. Press the color of the first TRUE rule.
1∃r ∀c (x is even)RED
2∀r ∃c (x = 0)BLUE
3∃c ∀r (x > 5)GREEN

Argument Check (needy)

  1. Wakes up now and then with a 40-second countdown.
  2. Y = valid · N = invalid.
  3. Never disarms. Keep answering it.
Valid → Y
p → q, p ∴ q
p → q, ¬q ∴ ¬p
p → q, q → r ∴ p → r
p ∨ q, ¬p ∴ q
p ∴ p ∨ q
p ∧ q ∴ p
∀x P(x) ∴ P(c)
P(c) ∴ ∃x P(x)
∀x (P(x) → Q(x)), P(c) ∴ Q(c)
¬∀x P(x) ∴ ∃x ¬P(x)
Invalid → N
p → q, q ∴ p
p → q, ¬p ∴ ¬q
p ∨ q, p ∴ ¬q
∀x (P(x) → Q(x)), Q(c) ∴ P(c)
∃x P(x) ∴ ∀x P(x)
¬∀x P(x) ∴ ∀x ¬P(x)
