LOGIC BOMB: Classic Edition v. 1Introduction

You are holding the only copy of the instructions.

Somewhere nearby, a colleague is staring at a ticking device and waiting for you to say something useful. They can see the bomb. You can't. You can read this manual. They can't.

Read carefully, speak clearly, and never guess.
The clock does not care how close you were.

LOGIC BOMB: Classic Edition v. 1Defusing Bombs

Defusing Bombs

A bomb explodes when its countdown timer reaches 0:00 or when it records too many strikes. The bomb is defused only when every module on it has been disarmed before time runs out.

Example Bomb

Modules

A bomb can hold up to eleven modules. Each one is separate and can be disarmed in any order. Section 1 covers regular modules. "Needy" modules never stay disarmed and are covered in Section 2.

Strikes

Every mistake the Defuser makes records a strike, shown above the countdown timer. Each strike makes the timer run faster. When the last allowed strike is recorded, the bomb explodes.

Gathering Information

Many instructions need details printed on the bomb's casing, such as the serial number, batteries, indicators and ports. The Defuser can turn the bomb over to read the top, bottom and sides. See Appendices A, B and C.

On the Subject of Wires

Several wires, one correct snip. Count twice, cut once.

A wires module has three to six wires. Only one of them must be cut. Wires are counted from the top down: the top wire is the first wire.

3 wires:

  • If there are no blue wires, cut the third wire.
  • Otherwise, if the first wire is white, cut the first wire.
  • Otherwise, if there is more than one blue wire, cut the last blue wire.
  • Otherwise, cut the second wire.

4 wires:

  • If there is more than one yellow wire and the last digit of the serial number is even, cut the first yellow wire.
  • Otherwise, if there are no black wires, cut the fourth wire.
  • Otherwise, if there is exactly one red wire, cut the third wire.
  • Otherwise, if the last wire is white, cut the first wire.
  • Otherwise, cut the second wire.

5 wires:

  • If the second wire is black and the bomb has a lit indicator, cut the second wire.
  • Otherwise, if there are exactly two red wires, cut the first red wire.
  • Otherwise, if there are no white wires and the serial number contains a vowel, cut the fifth wire.
  • Otherwise, if there are more yellow wires than blue wires, cut the last yellow wire.
  • Otherwise, cut the third wire.

6 wires:

  • If there are no red wires and the bomb has three or more batteries, cut the second wire.
  • Otherwise, if the first and last wires are the same color, cut the fourth wire.
  • Otherwise, if there is exactly one black wire, cut the black wire.
  • Otherwise, if the last digit of the serial number is odd, cut the sixth wire.
  • Otherwise, cut the fifth wire.

On the Subject of The Button

It begs to be pressed. Sometimes it should be held instead.

Follow the first rule below that applies:

  1. If the button is white and the label says "WAIT", hold the button and see "Releasing a Held Button".
  2. If the button is red and the bomb has two or more batteries, press and immediately release the button.
  3. If the label says "PUSH" and the bomb has a lit indicator, press and immediately release the button.
  4. If the button is blue, hold the button and see "Releasing a Held Button".
  5. If the bomb has a parallel port, press and immediately release the button.
  6. Otherwise, hold the button and see "Releasing a Held Button".

Releasing a Held Button

While the button is held, a colored strip lights up to the right of it. Release the button when the countdown timer shows the digit below in any position.

On the Subject of Simon

A pattern of lights that wants an answer in kind.

  1. One of the four colored pads will flash.
  2. Using the table below, the Defuser presses the matching color.
  3. The original pad flashes again, followed by one more. Press the matching color for each one, in order.
  4. The sequence grows by one each time until the module is disarmed. A wrong press is a strike and the current sequence starts over.

Section 2: Needy Modules

Needy modules can't be disarmed. They switch on from time to time and must be dealt with before their own countdown runs out.

Stay alert: a needy module can wake up at any moment.

On the Subject of Capacitors

It fills up. You drain it. Forever.

When active, the capacitor slowly charges and its countdown falls from 45. Hold the DISCHARGE lever down to drain it and push the countdown back up. If the countdown reaches 0, it records a strike.
